# Captures

Écrans tels qu'ils sont dans le code, avec les données de démonstration (`ocd_live_demo`), en français.
Refaites à chaque évolution avec `tools/captures/` (voir `docs/DEVELOPPEMENT.md`).

- `backoffice-*` : écrans de l'équipe sur ordinateur (1280 × 800), dont les paramètres (`12`), les
  automatisations (`13`), les tarifs de livraison (`14`) et les conversations WhatsApp (`15`).
- `site-phone-d-1-fil-pays.png`, `site-phone-d-3-fil-autre-pays.png`, `site-phone-d-4-fil-live-autre-pays.png` :
  le fil des lives avec la démo de présentation (le pays du visiteur d'abord, puis une carte par pays et
  ses lives en cours) ; `backoffice-01` et `backoffice-02` montrent sa journée et sa semaine du studio.
- `site-phone-*`, `site-tablet-*`, `site-desktop-*` : pages du site sur téléphone, tablette et ordinateur
  (`-d-` annuaire, `-s-` shop et livraisons ; `-s-8b`, `-s-8c` : un panier de deux vendeuses, un prix par
  colis).
- `site-phone-o-*`, `site-desktop-o-*` : pages d'Odoo (recrutement, menu du site, connexion) avec le
  thème « OCD Live » (`theme_ocd`), le logo, le pied de page et les coordonnées d'OCD Live, en français.
- `backoffice-16-choix-du-theme.png` : le thème « OCD Live » dans le choix des thèmes d'Odoo.
- `site-phone-l-*` : page « Tes colis à livrer » des livreurs : le numéro (`1`), le lien envoyé (`2`).
- `site-phone-v-*` : « Moi » avec un compte Odoo connecté : équipe (`1`), vue de l'équipe sur l'espace
  d'un vendeur (`2`), client avec son numéro prérempli (`3`).
