# Captures

Écrans tels qu'ils sont dans le code, avec les données de démonstration (`ocd_live_demo`), en français.
Refaites à chaque évolution avec `tools/captures/` (voir `docs/DEVELOPPEMENT.md`).

- `backoffice-*` : écrans de l'équipe sur ordinateur (1280 × 800).
- `site-phone-*`, `site-tablet-*`, `site-desktop-*` : pages du site sur téléphone, tablette et ordinateur
  (`-d-` annuaire, `-s-` shop et livraisons).
